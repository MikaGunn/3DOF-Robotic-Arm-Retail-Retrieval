# Attribution and Licensing Check

This repository contains a mixture of custom project code, ROS 2 packages, robot-description assets, trained model weights, testing artefacts, and supporting files.

Before publishing publicly:

- identify any packages or assets adapted from tutorials, vendor repositories, course starter code, or other open-source projects;
- retain the original copyright notices and license files where required;
- verify redistribution rights for trained model weights and datasets;
- verify that any screenshots, videos, and report figures may be published.

No new project-wide license has been added automatically because the ownership/licensing status of every component was not established from the uploaded files.
