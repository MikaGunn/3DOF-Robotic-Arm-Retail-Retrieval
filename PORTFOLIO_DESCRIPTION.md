# Portfolio Description

## Short Version

**3-DOF Robotic Arm for Retail Item Retrieval**  
Developed a ROS 2 based robotic manipulation system using analytical inverse kinematics, MoveIt 2 trajectory control, Gazebo/RViz simulation, and camera-based hybrid localisation for structured retail shelf item retrieval.

## Strong CV Version

Developed and tested a 3-DOF robotic arm for retail shelf item retrieval, integrating ROS 2, MoveIt 2, inverse kinematics, Gazebo/RViz simulation, Raspberry Pi based hardware control, and camera feedback for target-position refinement and stable multi-step approach motion.
