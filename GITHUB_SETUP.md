## Repository content

This folder contains the cleaned source code, ROS 2 packages, perception/control code, testing artefacts, documentation, model files, and configuration required for the final project.

Generated ROS 2 folders such as `build/`, `install/`, and `log/` are intentionally excluded.

## Before publishing

1. Review `ATTRIBUTION_NOTE.md`.
2. Check redistribution rights for any trained model weights, datasets, screenshots, or third-party assets.
3. Replace any remaining local absolute file paths used only for testing.
4. Test the repository on the ROS 2 environment you intend to document.
5. Do not upload the original academic report if you do not want your student ID publicly visible.
6. Add one short demo GIF or video link if you have a public demonstration.
